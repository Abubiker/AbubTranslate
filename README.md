# AbubTranslate

Выделить текст в любом приложении macOS, нажать `⌥⇧T` — перевод в панели.

Работает на Apple Translation: на устройстве, без ключей и без сети. Нужен
движок посильнее или язык, которого у Apple нет — подключается DeepL,
Google, Azure, Yandex, LibreTranslate, MyMemory или любой OpenAI-совместимый
сервер, включая локальный.

![platform](https://img.shields.io/badge/macOS-15%2B-black) ![swift](https://img.shields.io/badge/Swift-6-orange) ![license](https://img.shields.io/badge/license-GPL--3.0-blue)

## Установка

[Скачать AbubTranslate.dmg](https://github.com/Abubiker/AbubTranslate/releases/latest/download/AbubTranslate.dmg) — macOS 15+, Apple Silicon. Открыть образ, перетащить в Applications.

Сборка подписана сертификатом разработчика, не нотаризована. При первом
запуске: Настройки → Конфиденциальность и безопасность → Открыть всё равно.

## Хоткеи

| | |
|---|---|
| `⌥⇧T` | перевести выделенное |
| `⌥⇧Y` | озвучить последний перевод (панель может быть закрыта) |
| `⌥⇧S` | перевести картинку из буфера — скриншот `⇧⌘⌃4` или файл на панель |

Все три настраиваются. Занятая комбинация не сохраняется: и та, что занята
другим приложением, и та, что уже висит на другом действии AbubTranslate.

Клик по иконке открывает панель и больше ничего: не переводит и не трогает
буфер. Вставленный в панель текст переводится сам, через 500 мс после
последнего ввода.

Язык оригинала определяется автоматически. Целевой — один, по умолчанию язык
системы. Повторный перевод того же текста берётся из локального кэша (90 дней,
до 20 МБ) — мгновенно и без расхода квоты; над переводом видно, чем он
получен: `из кэша`, `на устройстве` или `DeepL · 1.9s`.

## Движки

Один активен за раз.

| Движок | Где работает | Условие |
|---|---|---|
| Apple Translation | на устройстве | встроен, без настройки; 22 языка на момент написания |
| MyMemory | облако | ключ не нужен; 5 000 символов/сутки анонимно, 50 000 с указанной почтой (не проверяется, регистрации нет — просто ключ лимита) |
| Azure Translator | облако | ключ подписки, portal.azure.com; тариф F0 — 2 млн символов/месяц, списать сверх лимита физически нельзя, пока сам не переключишь ресурс на платный |
| Google Translate | облако | API-ключ, console.cloud.google.com; платно сверх бесплатного лимита, барьера как у Azure F0 нет — за квотой следит пользователь |
| DeepL | облако | API-ключ, developers.deepl.com; бесплатный тир — разовый кредит 1 млн символов, не пополняется |
| OpenAI-совместимый | облако или локально | базовый URL и модель; ключ — если сервер требует. Подойдёт сам OpenAI, прокси, локальные Ollama/LM Studio |
| Yandex Cloud Translate | облако | API-ключ сервисного аккаунта со scope translate (консоль IAM) и привязанная карта — посимвольно с первого символа; для ключей обычного пользователя ещё folder ID |
| LibreTranslate | облако или локально | URL инстанса; пусто — публичный libretranslate.com (там ключ обязателен). Свой инстанс в docker работает без ключа |

**Что уходит в сеть.** Apple, локальный OpenAI-совместимый сервер на
`localhost` и self-hosted LibreTranslate не отправляют никуда ничего. Все
остальные отправляют переводимый текст на сторонний сервер.

Облачные движки при неудаче — нет ключа, кончился лимит, пара не
поддерживается — сами откатываются на MyMemory.

<details>
<summary><b>Как получить ключ: Azure, Google, DeepL, OpenAI-совместимый</b></summary>

### Azure

1. portal.azure.com → **Create a resource** → поиск «Translator» → создать.
2. Тариф — **F0 (Free)**: 2 млн символов/месяц, без платного пути, пока сам
   не переключишь ресурс на **S1**.
3. Карта при регистрации нужна только для верификации личности (Microsoft
   делает $1 холд, который снимается и не списывается).
4. **Keys and Endpoint** в боковом меню: там `KEY 1` и `Location/Region`.
5. Global-ресурс — регион можно не вписывать, оставить пустым.

### Google Translate

1. console.cloud.google.com → создать проект или выбрать существующий.
2. **APIs & Services → Library** → «Cloud Translation API» → **Enable**.
3. Нужен биллинг-аккаунт с картой: бесплатный лимит здесь не отдельный
   тариф, а месячный кредит против аккаунта с оплатой.
4. **APIs & Services → Credentials → Create Credentials → API key**.
5. Ключ стоит ограничить только Cloud Translation API — тогда утечка не
   откроет доступ ко всему проекту.
6. F0-аналога нет: кончился бесплатный лимит — платит карта. Следить за
   расходом: **Billing → Budgets & alerts**.

### DeepL

1. developers.deepl.com → free-аккаунт (карта для free-тира не нужна).
2. **API Keys** в личном кабинете → создать ключ.
3. Free-ключ отличается суффиксом `:fx` (например `279a...42a0:fx`) — по нему
   приложение само выбирает бесплатный эндпоинт.
4. Бесплатный лимит («Developer») — разовый кредит 1 млн символов, помесячно
   не пополняется: кончился — либо платный Growth, либо стоп.
5. Кнопка «Проверить лимит» показывает остаток, не выходя из приложения.

### OpenAI-совместимый

1. **Базовый URL** — `https://api.openai.com/v1`, или
   `http://localhost:11434/v1` для Ollama. Хвост `/chat/completions`
   дописывается сам.
2. **Модель** — идентификатор в том виде, в каком его ждёт сервер
   (`gpt-4o-mini`, `llama3.1`).
3. **Ключ** — обязателен для удалённых серверов. Для локальных (`localhost`,
   `127.0.0.1`, `::1`) можно оставить пустым: заголовок авторизации тогда
   просто не отправляется.
4. Кнопка «Проверить соединение» делает пробный перевод и говорит, отвечает
   ли сервер выбранной моделью.

MyMemory ключа не требует вообще — почту можно оставить пустой или указать
любую ради лимита побольше.

</details>

<details>
<summary><b>Что стоит знать про движки</b></summary>

**Проверено живыми запросами только MyMemory.** Azure, Google и DeepL
собраны строго по официальной документации, но живым запросом не проверены:
создание аккаунта с биллингом требует карту, а такое действие приложение за
пользователя не выполняет.

**Reasoning-токены.** OpenAI-совместимым моделям по умолчанию уходят поля,
отключающие размышления (DeepSeek `thinking`, Qwen `enable_thinking`, OpenAI
`reasoning_effort`) и потолок `max_tokens`: именно размышления — главная
причина «переводит по минуте». Сервер, отвергающий неизвестные поля,
получает автоматический повтор без них.

**Ключи применяются по кнопке «Сохранить».** Так же движок, регион Azure,
folder ID, адрес LibreTranslate и почта MyMemory. Языки, хоткеи, тема и
автозапуск применяются сразу. Причина: смена движка посреди набора ключа не
должна перезапускать перевод по недописанным данным.

**Офлайн-движка на скачиваемых нейросетях нет.** Единственный известный
источник CoreML-моделей перевода их не публикует — затея была обречена с
самого начала.

</details>

## Разрешения

Перевод выделенного требует Универсальный доступ (Настройки →
Конфиденциальность и безопасность). Выделение читается через Accessibility
API, буфер обмена не трогается. Если приложение выделение через AX не отдаёт
(типично для Electron) — уходит синтетический `⌘C`, а прежнее содержимое
буфера возвращается на место. Без разрешения остаются вставка в панель
руками и OCR с картинки; ему разрешение на запись экрана не нужно,
распознаёт Apple Vision локально.

Разрешение выдано, но не работает — осталась запись от прошлой сборки с
другой подписью. Удалить кнопкой `−` и добавить заново, либо:

```bash
tccutil reset Accessibility com.opensource.abubtranslate
```

<details>
<summary><b>Интерфейс и мелочи поведения</b></summary>

Интерфейс на 10 языках: английский, русский, испанский, французский,
немецкий, португальский, китайский, японский, арабский, хинди. По умолчанию
берётся язык системы; если перевода на него нет — английский, а для языков
постсоветского пространства русский, как более близкий этой аудитории.
Меняется в настройках и применяется сразу, без перезапуска.

При первом запуске — интерактивный онбординг: выбрать язык перевода, выдать
доступ и настоящим выделением проверить хоткей. Последний шаг засчитывается
только по реальному переводу.

Тема — системная, светлая или тёмная. На macOS 26+ панель и настройки
используют Liquid Glass поверх мягкой цветной подложки, на более ранних
версиях — обычные материалы.

Язык оригинала можно задать вручную в панели вместо автоопределения. Если
оригинал уже на целевом языке, панель предложит кнопкой перевести на
альтернативный — молча подменять цель она не станет.

Перевод можно вставить на место исходного выделения; `⌘Z` в целевом
приложении отменяет вставку, буфер возвращается.

Правый клик по иконке — меню: перевод скриншота из буфера, настройки, выход.

</details>

<details>
<summary><b>Сборка из исходников</b></summary>

macOS 15+, Xcode 16+, [xcodegen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
security find-identity -v -p codesigning   # найти свою identity
export ABUBTRANSLATE_SIGN_IDENTITY="Apple Development: ваш@email (TEAMID)"
./Scripts/build.sh
```

Результат: `/Applications/AbubTranslate.app` (скрипт сам ставит).
`Scripts/build.sh` — единственный правильный способ собрать проект, **даже
если собирает не эта сессия, а другой инструмент/агент**: голый
`xcodebuild` без ручной пересборки подписи подписывает ad-hoc, а это ломает
не только выданный Accessibility-грант, но и Keychain-доступ к уже
сохранённым API-ключам (Azure/Google/DeepL/OpenAI) — designated requirement
у ad-hoc это хеш бинарника (cdhash), он меняется на каждой пересборке,
macOS видит «другое приложение» и не даёт добраться до старых секретов.
Подробности — в комментарии в начале скрипта.

```
ad-hoc:      designated => cdhash H"3b95b95e…"
сертификат:  designated => identifier "com.opensource.abubtranslate"
                           and anchor apple generic
                           and certificate leaf[subject.CN] = "Apple Development: …"
```

У ad-hoc требование прибито к хешу бинарника — любая пересборка ломает и
выданное разрешение, и доступ к Keychain. У сертификата требование
привязано к нему самому и переживает пересборки.

`Scripts/build.sh` перед сборкой сам прогоняет две проверки и падает на
любой: полноту локализаций (`Scripts/check-locales.sh`) и тесты чистой
логики. Запустить их отдельно — выбор направления перевода, нарезка текста
под лимит запроса, сравнение версий:

```bash
swiftc -o /tmp/selfcheck Sources/Managers/TranslationDirection.swift \
    Sources/Managers/TextChunker.swift Sources/Managers/VersionCompare.swift \
    Tools/SelfCheck.swift && /tmp/selfcheck
```

### Структура

```
Sources/
├── TranslatorApp.swift            # @main, статус-итем, поповер, меню правого клика
├── AppModel.swift                 # состояние, движки, оркестрация перевода
├── Views/
│   ├── PanelView.swift             # основная панель
│   ├── SettingsView.swift          # языки, движки, хоткеи, тема
│   ├── HotkeyRecorder.swift        # запись комбинации
│   ├── OnboardingView.swift        # первый запуск: язык, доступ, проверка хоткея
│   └── DesignTokens.swift          # шкала размеров/отступов/цветов
├── Managers/
│   ├── SelectionReader.swift       # выделение через AX, синтетический ⌘C как запасной путь
│   ├── TranslationDirection.swift  # выбор альтернативного языка (чистая логика)
│   ├── TextChunker.swift           # нарезка под лимит запроса облачных сервисов
│   ├── TranslationProvider.swift   # протокол провайдера, EngineMode
│   ├── Providers/                  # MyMemory, Azure, Google, DeepL, OpenAI, Yandex, LibreTranslate
│   ├── CloudTranslator.swift       # HTTP-клиент MyMemory
│   ├── TranslationCache.swift      # дисковый кэш переводов, 90 дней / 20 МБ
│   ├── ImageOCRManager.swift       # OCR картинки из буфера через Apple Vision
│   ├── UpdateChecker.swift         # релизы GitHub, сверка sha256, самоподмена бандла
│   ├── VersionCompare.swift        # сравнение версий (чистая логика)
│   ├── KeychainHelper.swift        # хранение токена/почты
│   ├── ClipboardManager.swift      # NSPasteboard
│   ├── LanguageDetector.swift      # NLLanguageRecognizer
│   ├── SpeechManager.swift         # AVSpeechSynthesizer
│   ├── LaunchAtLogin.swift         # SMAppService
│   └── HotKeyManager.swift         # Carbon RegisterEventHotKey
├── {en,ru,es,fr,de,pt,zh,ja,ar,hi}.lproj/   # локализация, 10 языков
└── Assets.xcassets/
```

Новая строка в интерфейсе — это ключ во всех десяти `.lproj`, а не только
в `en`/`ru`: пропущенный ключ не даёт ни ошибки сборки, ни ошибки в работе —
вместо перевода показывается сам английский ключ, и заметить это можно
только глазами и только на том языке. Поэтому за этим следит
`Scripts/check-locales.sh`: сверяет ключи из кода со всеми десятью файлами,
ругается на недостающие и на дубликаты, запускается из `build.sh` до
сборки. Новый язык — ещё и код в `knownRegions` в `project.yml`, иначе
xcodegen не положит `.lproj` в бандл.

</details>
