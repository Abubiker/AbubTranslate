# AbubTranslate

Меню-бар переводчик для macOS. Проблема, которую решает: системный
переводчик Apple встроен только в Safari и Заметки — в остальных
приложениях перевести текст можно только скопировав его в отдельное окно
вручную. AbubTranslate даёт для этого один хоткей из любого приложения.

![platform](https://img.shields.io/badge/macOS-15%2B-black) ![swift](https://img.shields.io/badge/Swift-6-orange) ![license](https://img.shields.io/badge/license-MIT-green)

## Установка

[Скачать AbubTranslate.dmg](https://github.com/Abubiker/AbubTranslate/releases/latest/download/AbubTranslate.dmg) — macOS 15+, Apple Silicon.

Открыть образ, перетащить в Applications.

Сборка подписана сертификатом разработчика, не нотаризована. При первом
запуске: Настройки → Конфиденциальность и безопасность → Открыть всё равно.

## Использование

Два способа:

- Выделить текст в любом приложении, нажать `⌥⇧T` — панель откроется с
  переводом.
- Открыть панель кликом по иконке, вставить текст в поле «Оригинал» —
  перевод запускается сам, через 500 мс после последнего ввода.

Клик по иконке панель только открывает, ничего не переводит и не трогает
буфер обмена.

Язык оригинала определяется автоматически (можно задать вручную в панели).
Целевой язык — один, задаётся в настройках; по умолчанию язык системы.
Если оригинал уже на целевом языке — панель предлагает кнопкой перевести на
альтернативный, без автоподмены.

`⇄` — поменять оригинал и цель местами. `🔊` — озвучить перевод. `📋` —
скопировать результат. `⚙️` — настройки. Второй хоткей, `⌥⇧Y` — озвучить
последний перевод, работает при закрытой панели. Оба хоткея настраиваются;
занятая другим приложением комбинация не сохраняется, показывается
предупреждение.

Правый клик по иконке — меню: настройки, выход.

## Движки перевода

Настройки → Engine. Один активен за раз.

| Движок | Где работает | Условие |
|---|---|---|
| Apple Translation | на устройстве | встроен, без настройки; 22 языка на момент написания |
| MyMemory | облако | ключ не нужен; 5 000 символов/сутки анонимно, 50 000 с указанной почтой (почта не проверяется, регистрация не нужна — просто ключ лимита) |
| Azure Translator | облако | нужен ключ подписки: portal.azure.com, тариф F0 — 2 млн символов/месяц бесплатно, списать деньги сверх лимита физически нельзя, пока не переключишь ресурс на платный |
| Google Translate | облако | нужен API-ключ: console.cloud.google.com; платно сверх бесплатного лимита, жёсткого барьера как у Azure F0 здесь нет — следить за квотой на стороне пользователя |
| DeepL | облако | нужен API-ключ: developers.deepl.com, бесплатный тир — разовый кредит 1 млн символов (не пополняется, дальше платный Growth); ⚠️ **сам блокирует запросы с российских IP на уровне сети** |

Apple ничего не отправляет в сеть. MyMemory, Azure, Google и DeepL —
отправляют переводимый текст на сторонний сервер.

Azure, Google и DeepL при неудаче (нет ключа, лимит, пара не
поддерживается) автоматически откатываются на MyMemory — тот же принцип,
что и раньше.

Движок, ключ/регион Azure, ключ Google, ключ DeepL и почта MyMemory
применяются только по кнопке «Сохранить» в настройках — остальные поля
(языки, хоткеи, тема, автозапуск) применяются сразу. Причина: смена движка
посреди набора ключа не должна перезапускать перевод по недописанным
данным.

Azure и Google собраны строго по официальной документации — живым запросом
не проверены: создание аккаунта с биллингом требует карту, такое действие
приложение за пользователя не выполняет. DeepL по той же причине не
проверен живым запросом, но собран по документации developers.deepl.com,
которая читается напрямую без CAPTCHA. MyMemory проверен реальными
запросами.

### Как получить ключ Azure

1. portal.azure.com → **Create a resource** → поиск «Translator» → создать.
2. Тариф — **F0 (Free)**: 2 млн символов/месяц, физически бесплатно, без
   платного пути, пока сам не переключишь ресурс на **S1**.
3. Карта при регистрации нужна только для верификации личности (Microsoft
   делает $1 холд, который снимается и не списывается).
4. После создания ресурса — **Keys and Endpoint** в боковом меню: там
   `KEY 1` (это ключ) и `Location/Region`.
5. Global-ресурс — регион в приложение можно не вписывать, оставить пустым.

### Как получить ключ Google Translate

1. console.cloud.google.com → создать проект (или выбрать существующий).
2. **APIs & Services → Library** → найти «Cloud Translation API» → **Enable**.
3. Нужен биллинг-аккаунт с картой — без него включить платный API нельзя,
   бесплатный лимит здесь не отдельный тариф, а месячный кредит против
   аккаунта с оплатой.
4. **APIs & Services → Credentials → Create Credentials → API key**.
5. Ключ можно (и стоит) ограничить в настройках credential — разрешить
   только Cloud Translation API, чтобы утечка ключа не открывала доступ ко
   всему проекту.
6. Здесь нет F0-аналога — потратил бесплатный лимит, платит карта. Следить
   за расходом: **Billing → Budgets & alerts** в консоли.

### Как получить ключ DeepL

1. developers.deepl.com → зарегистрировать free-аккаунт (карта не нужна
   для free-тира).
2. **API Keys** в личном кабинете → создать ключ.
3. Free-ключ отличается суффиксом `:fx` (например `279a...42a0:fx`) — по
   нему приложение само выбирает бесплатный эндпоинт.
4. Бесплатный лимит («Developer») — разовый кредит 1 млн символов, не
   пополняется помесячно; кончился — либо платный Growth, либо стоп.
5. ⚠️ **DeepL сам блокирует запросы с российских IP на уровне сети** (не
   только оплату) — это не баг приложения.

MyMemory ключа не требует вообще — просто оставить почту пустой или
указать любую для более высокого лимита.

Офлайн-движка на базе локально скачиваемых нейросетей в приложении нет —
единственный известный источник CoreML-моделей перевода их не публикует,
скачивание было обречено с самого начала.

## Разрешения

Перевод выделенного текста требует Универсальный доступ (Настройки →
Конфиденциальность и безопасность → Универсальный доступ). Механизм:
приложение отправляет синтетический `⌘C`, читает результат, возвращает
прежнее содержимое буфера обмена. Без разрешения — только вставка текста в
панель вручную.

Разрешение выдано, но не работает: осталась запись от прошлой сборки с
другой подписью. Удалить кнопкой `−` из списка и добавить заново, либо:

```bash
tccutil reset Accessibility com.opensource.abubtranslate
```

<summary><b>Сборка из исходников</b></summary>

macOS 15+, Xcode 16+, [xcodegen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
xcodegen generate
xcodebuild -project AbubTranslate.xcodeproj -scheme AbubTranslate \
    -configuration Release -derivedDataPath .build build CODE_SIGN_IDENTITY="-"
```

Результат: `.build/Build/Products/Release/AbubTranslate.app`.

Подпись обязательна — без неё arm64-бинарь не запускается. Подписывать
сертификатом разработчика, не ad-hoc:

```bash
codesign --force --deep --options runtime \
    -s "Apple Development: ваш@email (TEAMID)" \
    .build/Build/Products/Release/AbubTranslate.app
```

Причина: macOS запоминает при выдаче «Универсального доступа» designated
requirement подписи.

```
ad-hoc:      designated => cdhash H"3b95b95e…"
сертификат:  designated => identifier "com.opensource.abubtranslate"
                           and anchor apple generic
                           and certificate leaf[subject.CN] = "Apple Development: …"
```

У ad-hoc требование прибито к хешу бинарника — любая пересборка ломает
выданное разрешение. У сертификата требование привязано к нему самому и
переживает пересборки.

Тесты чистой логики (выбор направления перевода, нарезка текста под лимит
запроса):

```bash
swiftc -o /tmp/selfcheck Sources/Managers/TranslationDirection.swift \
    Sources/Managers/TextChunker.swift Tools/SelfCheck.swift && /tmp/selfcheck
```
